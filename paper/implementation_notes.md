## 明确保持的参数

短面板：2,000 HVG，不做 patch，不加入 VAE/OT/MMD；12 层、宽 768、12 头；RMSNorm、QK-RMSNorm、SwiGLU（ratio=4）、AdaLN-zero；从第 4 层起 32 个条件 token；冻结 5120 维 ESM2，经线性投影用于基因身份；遗传扰动共享基因表示空间；时间、扰动、细胞条件相加。图 1 还包含 positional encoding。

Rectified flow：`z_t=t*x+(1-t)*epsilon`，预测 `v=x-epsilon`，均方速度损失；`sigmoid(N(-0.8,0.8²))`；扰动和细胞条件独立以 0.1 概率置空（正文明确独立，附录只重述扰动 dropout）。AdamW β=(0.9,0.95)、weight_decay=0；有效批量 512、lr=1e-4、warmup=5 epoch、cosine 最小 lr=0；BF16。按附录 A 保留 EMA=0.9999 / 0.9996，默认用后者推理。Heun 50 步（50 个区间），最后一区间 Euler；CFG 严格使用式 11。

## 已完成检查与小实验方案

- 确认公开压缩 H5AD 与 Arc 原文件逐字节相同；严格复现 Table 1 所有细胞数及验证/测试扰动数；训练/验证/测试 (cell line, perturbation) 组合不重叠。
- X_hvg 均值 0.4354，基因内标准差汇总 0.4553；不进行额外标准化或放大。固定原 2,000 HVG，不因缺失 ESM2 改变基因集合。
- 使用 56 个原始 gem_group 标签，与正文统计一致。不同 cell line 的同号 batch 由独立 cell-line 条件区分；曾检查组合后会有 215 个组合，但未采用 215-label 方案训练。
- 训练平均表达基线在验证集 PDCorr=0.4172、MSE=0.00782、PDS_L2=0.5097。说明单靠总体表达误差不能证明扰动预测有效；模型选择需同时看 PDCorr 和 PDS。
- 性能测试：完整 12×768 模型，microbatch 16/32 编译后均约 73 cells/s；32 的峰值约 29.2 GB，16 约 15.6 GB。64 即便 activation checkpoint 仍 OOM（编译器选择的重计算方案），不用于训练。选择 16×32 次累积，显存裕量支持双 EMA 和中途验证。
- 噪声小实验：同一随机种子、同一 16,384 训练子集，sigma=1.0 与 0.5 各 12 epoch（384 个优化步），均保留 5 epoch warmup、有效 batch=512 和双 EMA。全验证集固定 1,024 细胞做去噪探针；最终全部 60 个验证扰动每扰动最多 16 个细胞做 50 步生成。
- 384 步远小于 EMA 的有效时间尺度，故**小实验生成使用原始权重作诊断**，并同时记录原始/EMA 去噪误差；小实验原始权重不允许作为最终测试复现模型。完整训练与正式推理使用 EMA=0.9996。这里不是将 pilot 指标冒充论文结果。
- 在正式全量训练前，把小实验扩展为 sigma∈{1,0.5} × time_scale∈{1,1000} 共 4 组。原因：原文未说明时间嵌入频率；JiT 的 raw t 编码来自 x-pred，而本文默认是更依赖时间条件的 v-pred。需要检验 raw t 的弱变化是否影响收敛，不能在长训练后才发现。两种时间缩放只作用于网络的 sinusoid 编码；flow 路径和时间采样仍严格为原文的 [0,1] 与 logit-normal。其余参数、训练子集及随机种子相同。
- 训练引擎 smoke test 已通过；checkpoint 测试还验证恢复优化器、两组 EMA、CPU/GPU 随机状态后下一步精确一致。每 50 个优化步及每 epoch 原子写检查点，故普通中断最多损失约 6 分钟计算；SIGTERM/SIGINT 在当前优化步后安全保存。
- 训练按细胞均匀随机采样、不放回，逐轮用独立确定性置乱；全量每轮 1,118 个完整 512-cell batch，末尾 129 个细胞当轮不使用，下一轮重新置乱。这是未公开的 sampler / drop-last 细节，保持有效 batch 与 EMA 更新定义一致；验证/测试无丢弃。梯度裁剪默认关闭（原文未指定），但每优化步检查 loss / gradient finite，异常时保留上一份有效检查点。

## 指标实现核对

使用 Cell Eval 0.8.2 / pdex 0.3.0，保存完整源码及环境锁。已额外下载论文发布日期前的 Cell Eval commit `44f9009d6f3d4a4f944cba333c96ed258dd0d973`（0.7.2）：9 项论文指标的核心算法与当前版本相同，`_types/_anndata.py` 逐字节相同，DE 排序/重合与方向实现相同；后续新增 ceiling 等功能不参与本实验。当前 wrapper 固定 epsilon=0、关闭 CPM filter，保持旧版 DE 默认行为。3 个真实验证扰动的 identity smoke test 得到 PDCorr≈1、全部 PDS/DE=1、MSE=MAE=0，确认评估路径贯通。

Cell Eval 的入口会拒绝负表达。对于未截断的生成诊断，只直接调用同一工具的 array metric 函数，避免自动变换；正式 DE 评估要求非负表达。生成原始预测始终保存，是否截断只由验证集决定并单独记录。

中途生成的 cap 只限制预测细胞数；真实参考始终使用对应扰动的全部验证细胞，以减少选择配置时的参考均值噪声。每次评估保存 `population_counts.json` 和真实索引。正式测试不设 cap，生成数与全部 26,878 个测试扰动细胞一致。

全量训练在第 1、2 轮额外做每扰动最多 8 个细胞的原始权重生成诊断，专门检查条件是否学好；它不参与正式最佳模型选择。正式验证每 5 轮使用 EMA=0.9996、每扰动最多 32 个预测细胞；推理校准与测试均禁止使用原始诊断权重。采样前先保存已完成训练的检查点。启用非负后处理时，另存 `prediction_raw.npy`，避免只保留截断后的结果。

全量训练收敛规则：至少 20 epoch，最多 100；正式验证评分为 PDCorr + 三种 PDS 的均值。评分连续 10 epoch 没有达到 0.002 的改善时停止；最佳权重仍保留实际最高评分，不受该最小改善阈值影响。两个早停状态随检查点保存。该规则用于原文未公开的训练长度选择，原文明确的模型、批量、学习率缩放、warmup 和损失参数保持不变。A100 热稳态约 65–70 cells/s，全量每轮约 2.3–2.5 小时。

## 长面板数据的来源歧义

Table 5 / §4.3 将 18,080-gene 输入称为 Replogle–Nadig，§3.5 又称来自 AIVC 并引用 [23] Virtual Cell Challenge。已核对 Arc 官方数据仓库说明：该引用的数据是 H1 hESC（约 300,000 cells / 300 targets），并非本次 Table 1 的四细胞系 Replogle–Nadig。固定公开 `replogle.h5ad` 只有 6,642 个 X 基因、2,000 个固定 HVG，不能恢复不存在的 18,080 维。来源证据：https://github.com/ArcInstitute/arc-virtual-cell-atlas/blob/main/virtual-cell-challenge/README.md 。因此先完成能精确核对数据和划分的 Table 3 主基准，不把另一个 H1 数据集或补零的伪长面板冒充 Table 5 复现；此项歧义与尚未运行的 control-context / MMD 消融会在最终范围中明确列出。

11-18 03:18 二次核查进一步保存了官方证据：Arc GCS 的 `gene_names.csv` 确为 18,080 个唯一基因（无表头）；三个 split 的官方计数 CSV 为 150 / 50 / 100 个扰动、183,097 / 60,751 / 132,670 个扰动细胞，均与 Table 1 不同。该基因表与 Replogle 固定 HVG 按原始符号精确重叠 1,865/2,000（未做别名校正，不能直接解释为生物学缺失）。Arc README 以及另一研究团队的原始仓库均将此面板归为 VCC/H1。只读取对象元数据并下载 121,719 bytes 的四个 CSV，没有下载 H1 表达矩阵或 FASTQ；对象 generation、MD5/SHA256、GitHub 文件 SHA 和计数对比已保存到 `paper/long_panel_source_audit.json`、`paper/vcc2025_metadata/`。这表明现有引用不能唯一确定匹配 Replogle 的长面板，不等于证明作者另有数据不存在；仍不据此混用数据或声称 Table 5 已完成。当前主训练及其数据不变。

## 轮末评估的中断恢复修复
