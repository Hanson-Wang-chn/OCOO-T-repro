# OCOO-T 复现（Replogle–Nadig）

在本机 A100 40 GB / conda `ocoo-t` 上独立实现 [OCOO-T v2](https://arxiv.org/abs/2606.12838v2)。只下载和运行 Replogle–Nadig，未下载 Tahoe100M / PBMC。

**当前：六组小实验已完成，第一版全量主训练 `runs/main_v1` 已启动。完整验证、测试尚未完成，不宣称达到论文结果。**

## 数据与方法

| 划分 | 扰动细胞 | 扰动数 | 细胞系 |
| --- | ---: | ---: | --- |
| 训练 | 572,545 | 2,013 | 4 |
| 验证 | 4,825 | 60 | HepG2 |
| 测试 | 26,878 | 380 | HepG2 |

另有 39,165 个真实对照。公开数据与 Arc 原发布 SHA256 完全一致，已做 efficacy QC / 库大小归一化 / log1p；沿用固定 2,000 HVG 与官方留出列表，不重复归一化。56 个 batch。ESM2 匹配 3,545/3,618 基因，70 个 HVG 的缺失处理已记录。

主模型为 12 层、768 宽、12 头的连续基因 Transformer，含 RMSNorm、QK-norm、SwiGLU、adaLN-zero、第 4 层起的 32 个条件 token；直接在 2,000 HVG 上做 v-prediction rectified flow，不 patch。AdamW、有效 batch=512（microbatch=16，累积 32 次）、lr=1e-4、5 轮 warmup、cosine、BF16、双 EMA 保持论文设置。正式推理用 EMA=0.9996、50 步 Heun，末步 Euler。

论文未公开的细节与依据见 [implementation_notes.md](paper/implementation_notes.md)。全量选择为 noise_std=1、time_scale=1、cell_init_std=1；总训练上限 100 轮，至少 20 轮后按预设验证收敛规则停止。每轮约 2.3–2.5 小时；第 1、2 轮做提前条件诊断，第 5 轮起每 5 轮做 EMA 生成验证。CFG 只用验证集校准，测试不参与选型。正式非负预测与未截断预测均保存。

## 小实验

相同 16,384 个训练细胞、种子、12 轮 / 384 个优化步；每个验证扰动最多生成 16 个细胞、50 步。下表使用原始权重诊断和非负后处理，**不是论文正式推理或最终测试成绩**；综合选型含三种 PDS。

| 噪声 σ | 时间尺度 | cell 初始 std | PDCorr | PDS_L2 | MSE |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 1 | 0.02 | -0.0100 | 0.5039 | 0.07767 |
| 0.5 | 1 | 0.02 | 0.1088 | 0.5175 | 0.04038 |
| 1 | 1000 | 0.02 | -0.0007 | 0.5036 | 0.07374 |
| 0.5 | 1000 | 0.02 | 0.1292 | 0.5281 | 0.04472 |
| 1 | 1 | 1 | 0.2299 | 0.5183 | 0.01357 |
| 0.5 | 1 | 1 | 0.2070 | 0.5308 | 0.01624 |

第五组综合分数最高，并修正了明显的细胞类型偏差；PDS 仍接近随机，需要全量训练学习扰动特异性。完整对比见 `runs/pilot_comparison.json`，选型依据见 `runs/main_selection.json`，质心与方差诊断见 `runs/pilot_diagnostics/`。

## 运行与恢复

```bash
conda activate ocoo-t
python scripts/download_data.py       # 仅 Replogle，断点下载与 SHA256 校验
python scripts/prepare_data.py        # 验证固定 HVG / 拆分，生成训练缓存
python -m pytest -q
python scripts/run_experiment.py --config configs/main_selected.yaml
python scripts/status.py             # 只读进度
```

README 按你的要求每 **15 分钟**汇总刷新一次，逐步日志和检查点仍照常保存。
